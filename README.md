# UniGo - Ride-Sharing App for the Stanford Community

UniGo is a mobile ride-sharing application designed to enhance the 5SURE campus safety ride service at Stanford University. Built as a senior project, UniGo aims to improve accessibility, efficiency, safety, and communication for students requesting rides.  

## Features  
- **Real-time messaging** between drivers and passengers  
- **Location tracking** for live updates and efficient ride coordination  
- **Carpooling options** to reduce waiting times  
- **Dual access** through the app or direct dispatcher calls  
- **Safety-first design** with priority pickup for vulnerable users  

## Technologies Used  
- **Front-End:** React Native  
- **Back-End:** Firebase for real-time data and user authentication  
- **Mapping:** Google Maps API for route optimization  
- **Communication:** GiftedChat for in-app messaging  

## Impact  
The traditional 5SURE service at Stanford currently relies on walkie-talkies and spreadsheets for coordination, leading to long waiting times and communication gaps. UniGo modernizes the system by integrating real-time messaging, location tracking, and automated ride matching, offering a faster, more reliable, and safer ride-sharing experience.
